Clean up your smart TV with Claude Code

Your TV came stuffed with apps you never asked for. Claude Code can connect to it, list every app, and turn off only the ones you pick. Nothing gets deleted, and every step below can be undone.

The steps

  1. Turn on developer mode on your TV
    Open the build number and select it 7 times with your remote, until the TV says you are a developer. Google TV: Settings > System > About > Android TV OS build Android TV: Settings > Device Preferences > About > Build
  2. Turn on debugging
    Open the new Developer options menu and turn on USB debugging. If you also see Network debugging, turn that on too. Google TV: Settings > System > Developer options Android TV: Settings > Device Preferences > Developer options Menu names change a little by brand. If yours looks different, look for Developer options near About in Settings.
  3. Write down your TV's IP address
    It is in your TV's network settings: open Network & Internet, then your Wi-Fi network. It looks like 192.168.1.23.
  4. Open Claude Code on your computer and paste this
    The first line is the exact prompt from the video. The rest keeps it safe. Swap in your TV's IP address.
    prompt.txt
    Find my TV on this network, connect to it, list every app on it, and tell me which ones are safe to turn off. Don't touch anything until I say yes.

My TV's IP address is [YOUR TV IP]. Connect with adb on port 5555. If I give you a Wireless debugging pairing code instead, pair with adb pair and connect on the port shown under Wireless debugging, not 5555. If adb is not installed, ask me before you install Android platform tools.

Rules:
- Show me every app with one plain-English line on what it does, then wait for my picks.
- Only turn apps off with: adb shell pm disable-user --user 0 [app]. Never uninstall anything.
- Never touch the home screen launcher, Google Play services, the Play Store, Settings, system UI, setup, the on-screen keyboard, accessibility, Android System WebView, the package installer, TV and system providers, or anything for the remote, Bluetooth, Wi-Fi or inputs.
- If you are not sure what an app does, mark it "leave on".
- Turn off one app at a time and add each name to tv-disabled.txt so I can undo it.
  5. Say yes on the TV
    The first time Claude connects, your TV shows Allow USB debugging? Pick Allow with your remote. Then Claude shows you the list, you pick, and it turns them off.
  6. Turn debugging back off when you're done
    Same menu as step 2. Switch USB debugging (and Network debugging, if you turned it on) back off, so your TV is not left open to debugging connections.
Safety: turn off, never uninstall
  • Turned off is not deleted. pm disable-user only switches an app off. It stays on the TV and can come back any time.
  • Never uninstall system apps. If Claude ever suggests pm uninstall, say no. Deleting the wrong thing is how people break their TVs.
  • Undo one app: ask Claude to turn it back on, or run adb shell pm enable [app].
  • Undo everything: tell Claude "Turn back on every app in tv-disabled.txt."
  • See what is off: adb shell pm list packages -d
  • Last resort: a factory reset turns every built-in app back on, but it erases everything else on the TV: your downloaded apps, accounts and settings.
Claude can't connect to the TV

Check both are on the same Wi-Fi and that you picked Allow on the TV. Some newer Google TV models use Wireless debugging instead: turn it on in Developer options, choose Pair device with pairing code, and tell Claude the pairing IP address, port and code it shows, plus the IP address and port on the Wireless debugging screen. Claude pairs with adb pair, the method in Google's adb guide. If your TV has neither Network debugging nor Wireless debugging in Developer options, it cannot be reached over Wi-Fi, and this guide will not work on it.

Do I need to install anything?

Claude Code, plus Google's free Android platform tools (that is where adb comes from). The prompt tells Claude to ask before it installs them.
